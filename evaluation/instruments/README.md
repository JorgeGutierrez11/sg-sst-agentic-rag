# evaluation/instruments/

Instrumentos usados para evaluar el sistema con consistencia metodológica.

- expert_rubrics/   rúbricas del experto SST para validar respuestas y diagnósticos
- user_surveys/     encuestas Likert, formularios post-sesión e instrucciones al participante
- protocols/        guiones de sesión, consentimiento, criterios de muestreo y procedimiento

Aquí vive la definición del instrumento; los resultados de su aplicación NO van aquí,
van en `evaluation/results/` o en `evaluation/resultados_usuarios/` si contienen datos
crudos/confidenciales.
